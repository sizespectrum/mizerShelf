# Proportion of carrion production that is of human origin

Calculates or sets what proportion of the total carrion production is
from either excess gear mortality or from discards.

## Usage

``` r
carrion_human_origin(params)

carrion_human_origin(params) <- value
```

## Arguments

- params:

  A MizerParams object

- value:

  The desired proportion of carrion production that is of human origin.
